# Twitter Project

An improved Twitter-style tweet detail UI built with semantic HTML, responsive CSS, and modular vanilla JavaScript.

## Features

- Reusable post rendering
- Accessible buttons and labels
- Optimistic likes and bookmarks with rollback
- Debounced search with result filtering
- Reply composer with live character count
- Infinite scrolling with loading and retry states
- `localStorage` persistence
- Responsive three-column layout that adapts to smaller screens

## Run

Use a local static server and open `twitterproject/index.html`.
